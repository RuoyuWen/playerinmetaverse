# Chicken Frontier / 小鸡防线

将整个 chicken-frontier 文件夹上传到个人网站的静态目录，即可通过该文件夹的网址游玩。
例如放在 games/ 目录后，入口是 /games/chicken-frontier/ 。

index.html 已包含中英文编辑器、试玩、角色图片和所有音效，不需要安装依赖、后端服务器或 ChatGPT 登录。
本包未包含用户的自定义存档；需要时在原编辑器中导出 JSON，再到新网址导入。
存档按网址保存在浏览器本地；不同域名之间不会自动同步。
音效许可证和来源记录位于 licenses/ 。

Upload the complete chicken-frontier folder to your website's static directory.
The index.html file embeds the game, artwork and audio. No installation, backend or ChatGPT sign-in is required.
Custom browser saves are not included; export and import your project JSON when moving between domains.
Keep the audio license and credits in licenses/ when distributing this package.
