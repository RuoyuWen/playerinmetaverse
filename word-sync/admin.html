对局记录

每局结束（猜中或血量耗尽）时，think-aloud 文字、用时和猜测次数会自动上传到这里。

游戏规则

新设置对之后开始的对局生效，正在进行的对局不受影响。

AI 对手

开启并填好 API key 后，游戏开始界面会出现“和 AI 玩”。每一轮开始时服务器调用一次模型；模型的回复必须是 JSON，其中 think 会作为 AI 这一轮的文字保存，response 作为 AI 写的词。

每轮服务器会把当前局面作为一条 JSON 消息发给模型，包含：language、round、lives_left、start_word、previous_rounds（每轮的 your_word 和 partner_word）、words_already_used。模型看不到玩家本轮还没提交的词。


        
API key 保存在你的数据库里（未加密），只有后端会读取，不会发给玩家，也不会在这个页面上显示。
